# agent-playground

A tiny sandbox for exercising the [dsh-superagent](https://github.com/deepseek-ai/dsh-superagent-prototype)
research prototype: a proactive agent that watches this repository, turns requests into Tickets, and
answers with pull requests.

Nothing here is important. It exists so an agent has something harmless to work on.

## Greeting module

`src/greet.js` builds a greeting string. `tests/greet.test.js` checks it.

Run the tests:

```
node --test
```
